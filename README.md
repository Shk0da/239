# Тренажёр 239 — офлайн-APK

Android-приложение [математического тренажёра](https://ianshkondin.com/239/)
(1036 задач из пособия Л. С. Михлина для поступающих в 5 класс
физико-математических школ): сайт целиком упакован в APK и работает
из коробки **без интернета**. Работает от **Android 5.0 (API 21)** —
проверено на эмуляторе Android 5.0 с заводским WebView (Chromium 37):
для старых WebView инжект добавляет полифил `closest` (нужен и самому
сайту) и читает blob-URL экспорта через XHR вместо `fetch`.

Сборка повторяет подход [Wallet](https://github.com/Shk0da/Wallet) —
WebView-обёртка над офлайн-бандлом, без Gradle: `aapt2 → javac → d8 →
zip → zipalign → apksigner`.

## Возможности

- 📱 Весь тренажёр как есть: 4 вкладки, автопроверка, подсказки, план, цель
- 🔔 Напоминания о занятиях: карточка «Напоминания» во вкладке «Цель» —
  время и вкл/выкл; уведомление приходит в выбранное время, только если
  на этот день есть занятие по плану с нерешёнными задачами
  (переживает перезагрузку — BootReceiver + снапшот)
- 🌑 Тёмная тема «Вечер» — строка состояния синхронизируется с темой вёрстки
- 💾 Прогресс в `localStorage` (переживает перезапуски, попадает в бэкапы системы)
- 📤 Экспорт прогресса — файл уходит в **Downloads** через мост `T239`
- 📥 Импорт прогресса — системный выбор файла (SAF)
- ✂️ Подвал сайта с технической справкой (про проверку ответов и файлы данных)
  в приложении скрывается — только задачи

## Структура

```
site/                    зеркало сайта (index.html, 239.js, answers.js, img/,
                         *.pdf — исходное пособие Михлина)
android/
  app/src/main/          манифест, MainActivity, ресурсы, иконки
  assets/www/            офлайн-бандл (собирается из site/)
tools/
  build-www.sh           site/ → android/assets/www/ + контроль автономности
  build-apk.sh           сборка APK без Gradle (SDK качается при первом запуске)
  gen-icons.php          иконки (PNG, GD): «239» серифом на «тёплой бумаге»
  test-offline.mjs       смоук-тест бандла в jsdom: сеть выключена
  run-emulator.sh        прогон в headless-эмуляторе (ставит, открывает, скриншот)
  cdp-eval.mjs           JS в живом WebView через CDP (debug-сборки)
dist/t239.apk            результат сборки
```

## Сборка

Windows (git-bash; нужны `java`/`javac`/`keytool` — JDK 17+, `python`,
`php` с GD, `unzip`, `openssl`):

```bash
./tools/build-apk.sh
```

Первый запуск скачает Android SDK (build-tools 34 + platform 34) в
`tools/android-sdk/` и сгенерирует подпись `tools/t239.keystore`
(пароль — в `tools/keystore.properties`). Повторные запуски собирают за
полминуты.

Проверка бандла без телефона:

```bash
npm install && npm test
```

## Обновление данных сайта

```bash
# переложить свежие index.html / 239.js / answers.js / img/ в site/ и:
./tools/build-apk.sh
```

`build-www.sh` откажет в сборке, если в бандле появится внешний URL
или 239.js сослётся на отсутствующую картинку.

## Как обёртка дружит с сайтом

Код сайта не меняется. `MainActivity` после загрузки страницы inject'ит
небольшой скрипт, который:

- перехватывает клик по `<a download>` (экспорт прогресса через blob-URL
  в WebView сам не скачивается) и отдаёт файл мосту `T239.saveFile`;
- следит за `data-theme` на `<html>` (кнопка «☾ Вечер») и красит строку
  состояния в цвет фона вёрстки;
- убирает подвал сайта с технической справкой (в приложении он не нужен);
- добавляет во вкладку «Цель» карточку «Напоминания» (время + вкл/выкл,
  ключ localStorage `p239_notify`; сайт перерисовывает вкладку — карточка
  возвращается через MutationObserver);
- патчит `Storage.prototype.setItem`: каждое сохранение прогресса
  (`p239_state_v2`) обновляет снапшот `t239-snapshot.json` — из него
  `NotifyReceiver` (ежедневный будильник) знает план и решённость,
  а `BootReceiver` восстанавливает будильник после перезагрузки.

`alert()/confirm()` сайта показываются нативными диалогами Material,
импорт файла — через `onShowFileChooser`, «назад» — двойное нажатие
(SPA без истории, иначе случайный тап закрывал бы приложение).

Разрешения: уведомления (`POST_NOTIFICATIONS`, Android 13+), точные
будильники (`USE_EXACT_ALARM`/`SCHEDULE_EXACT_ALARM` — без разрешения
фолбэк на окно ~15 минут) и `RECEIVE_BOOT_COMPLETED`. Сети по-прежнему нет.

## Старые Android (5.0 – 6.x)

- minSdk 21; лямбды десугарируются d8, версии API моложе 23 обойдены
  условиями (`setExactAndAllowWhileIdle`→`setExact`, `FLAG_IMMUTABLE`,
  каналы уведомлений, `LIGHT_STATUS_BAR`).
- На необновлённом WebView (Chromium ≤ 40) работает всё, включая вкладки
  сайта (полифил `closest`) и экспорт (XHR вместо `fetch`); на Android 5–9
  экспорт и PDF пишутся в `Android/data/…/files/Download` без разрешений,
- Напоминания на 21–22 идут через `setExact` (Doze там нет), на 23+ —
  `setExactAndAllowWhileIdle`, на 12+ без разрешения — неточное окно.
